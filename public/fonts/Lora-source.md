# Lora

Variable normal and italic, weights 400–600, Cyrillic, Latin and Latin extended subsets.

Source: [Google Fonts](https://fonts.google.com/specimen/Lora), [upstream distribution and license](https://github.com/google/fonts/tree/main/ofl/lora). Downloaded from the Google Fonts CSS API and fonts.gstatic.com on 2026-11-05. Fonts are served locally; the application makes no Google Fonts requests.

License: SIL Open Font License 1.1, included in Lora-OFL.txt.
