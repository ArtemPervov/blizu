Проверено 30 октября 2026 года.

| Проверка | Результат |
| --- | --- |
| `npm run build` | TypeScript frontend/backend и production-сборка Vite завершены успешно |
| `npm test` | 8 интеграционных тестов, 8 успешно |
| SQLite на диске | Данные и сессия сохранились после закрытия и повторного открытия базы |
| Docker Compose YAML | Оба файла разобраны; проверены сервисы, постоянный том, отсутствие опубликованного API и разделение сетей |
| Браузер — desktop | Проверены главный экран, поиск на кириллице, вход/выход, личный кабинет, каталог, форма предложения и заказ |
| Браузер — mobile | Ширина 390 px: меню, форма доставки, создание заявки; горизонтального переполнения нет, сломанных изображений нет |
| Собранный клиент и скомпилированный API | Проверены через временный локальный сервер с тем же CSP, что в Nginx: вход и отслеживание заказа работают, ошибок консоли этой сборки нет |

Сборка предупреждает о размере чанка Three.js (около 895 КБ, около 243 КБ gzip); это не ошибка сборки.

## Обновление эффектов React Three Fiber

Добавлены световые маршруты с движущимися точками, шейдерные блики, многослойные частицы с откликом на указатель, волна от клика и параллакс фото/плашек. В карточке и на странице доставки используется объёмная посылка с мягким парением, поворотом за указателем и орбитами.

- TypeScript и production-сборка проходят.
- В браузере проверены маршруты, параллакс от указателя, главная, миниатюра посылки и страница доставки.
- На ширине 390 px главный экран и доставка не имеют горизонтального переполнения; текст и кнопки остаются доступными.
- Жизненный цикл учитывает отдельные состояния видимости блока и вкладки; время сцены не скачет после возвращения. Для touch снижен DPR и количество геометрии; reduced motion отключает движение и реакции указателя.
