# Проверки сервиса

## dev — семь визуальных улучшений, 5 ноября 2026 года

- Реализованы все семь согласованных направлений: типографика Lora/Manrope, иерархия главной, карточки предложений, общая модель стекла, этапы заказов и следующие действия, фирменные иллюстрации и уведомления, микроанимации и раскрытие панелей.
- `npm test`: **23/23** — 9 API и 14 UI/API. Проверены три/пять этапов, отдельное состояние спора, подтверждение получения через реальный PATCH API с обновлением этапа, следующие действия по реальным данным, aria-expanded/aria-hidden/inert ответов FAQ и сохранение избранного после закрытия уведомления.
- `npm run build`: TypeScript frontend/backend и production-сборка проходят. Известное предупреждение размера ленивого Three.js-чанка сохраняется.
- HTTP-проверка собранных страниц и ресурсов с CSP проходит. Все шесть локальных файлов Lora возвращают 200 с MIME font/woff2 и корректной сигнатурой WOFF2; кириллица предварительно загружается. В CSS шрифтов нет запросов к Google Fonts. Лицензия OFL и источник приложены.
- Синтаксис CSS разобран PostCSS. Основные пары цветов сохранили контраст 13,56:1 / 4,95:1 / 6,70:1. Reduced motion и непрозрачный fallback предусмотрены в CSS; их фактическое отображение требует браузерной проверки.
- Штатный браузер снова недоступен: `failed to write kernel assets`, OS error 3. Геометрия, фокус нативного диалога, фактическое отображение шрифта, стекла и анимаций в этой итерации не подтверждены браузером; новых скриншотов нет. JSDOM не заменяет эту проверку. Сохраняются предупреждения тестового окружения об act и смешанном импорте Three.js.
- Контейнерная конфигурация и env не менялись. Docker runtime не запускался.

## Обновление эффектов React Three Fiber

Заголовок главной собирается из вихря частиц, рассчитанных по форме букв и метрикам локального шрифта. После сборки он плавно переходит в обычный HTML-заголовок, а Canvas удаляется. Нажатие на заголовок повторяет эффект. Изменение ширины завершает анимацию; reduced motion и отсутствие WebGL оставляют обычный текст. Предусмотрен возврат текста при ошибке запуска сцены.

Большое фото и фотографии каталога используют мягкую оптическую глубину, преломление и световой перелив. Летающие точки и маршруты с фото убраны. Фото стали крупнее; каталог показывает три карточки в ряд на desktop, две на средней ширине и одну на mobile. Canvas отдельной карточки появляется только при наведении мыши или фокусе клавиатуры. В блоках доставки сохранена 3D-посылка.

- Проверена собранная версия с CSP из конфигурации Nginx: ошибок и предупреждений консоли нет.
