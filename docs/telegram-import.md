# Импорт Telegram в локальную dev-версию

В Telegram Desktop экспортируйте группу `montenegrobye` (ID `1860715803`): JSON, фотографии, период за последние несколько недель. Дождитесь окончания экспорта. Прерванный JSON, HTML и другие группы импортёр отклоняет.

Предпросмотр без изменения базы:

```powershell
npm.cmd run import:telegram -- --export "C:\путь\ChatExport_2026-11-06"
```

После проверки выборки добавьте `--apply` для записи. Необязательный `--wait` ожидает завершения JSON до 12 часов. По умолчанию незавершённый файл сразу вызывает ошибку.

Команда использует только `data/blizu.sqlite` текущего проекта и требует демо-аккаунт; `DATA_DIR` намеренно игнорируется. При `NODE_ENV=production` запуск запрещён. Перед записью создаётся согласованная SQLite-копия через `VACUUM INTO` в `backups/before-telegram-*.sqlite`.

## Отбор и ограничения

- Выбираются 100 последних уникальных объявлений по времени исходного сообщения. Служебные записи, короткие ответы, объявления с пометкой «продано» в начале и точные повторы отбрасываются. Для записи нужны ровно 100 подходящих объявлений.
- Отбор и определение категории используют эвристики, без внешнего ИИ. Объявления без текстового описания не распознаются. Исходный текст сохраняется.
- Альбомы объединяются по `media_group_id`, если он есть. Иначе используется осторожное правило: соседние фото одного автора, соседние ID, интервал не больше двух секунд, без второй отдельной подписи. Максимум 10 фото на карточку. Распознавание всех альбомов не гарантируется.
- Сохраняются дата, отображаемое имя автора и ссылка на оригинал. Числовой Telegram ID автора и служебные сведения экспорта в публичный API не передаются.
- Город указывается при однозначном совпадении. Иначе интерфейс предлагает уточнить его у автора.
- Единственная однозначная сумма в евро показывается как цена. Несколько сумм или валют остаются в тексте; карточка показывает «Цены в объявлении» / «Цена не указана». Бесплатные предложения различаются отдельно. При фильтрации по цене карточки с неопределённой ценой исключаются, при сортировке стоят в конце.

Предпросмотр сохраняется в `.context/telegram-import-report.json`. Перед первым применением проверьте выборку. Повторный запуск пропускает уже импортированные ссылки и тексты; существующие карточки и модерация не переписываются. Для изменённого объявления с прежней ссылкой автоматического обновления пока нет.

## Витрина и хранение

После импорта появляется переключатель «Из Telegram». Адрес подборки: `/?source=telegram&sort=newest#catalog`. Работают поиск, категории, сохранение, сравнение и модерация. Карточка показывает автора Telegram, происхождение и исходную дату. Кнопка ведёт к оригиналу: там можно связаться с автором и проверить актуальность. Заказ через blizu для внешнего объявления не предлагается. Системный аккаунт источника не позволяет войти в сервис и не получает вымышленных отзывов или отметок.

Фотографии копируются в `data/uploads/listings/` с именами по SHA-256. Проверяются границы папки экспорта, сигнатура JPEG/PNG/WebP и размер до 10 МБ. API отдаёт только фото конкретной карточки и проверяет её видимость; скрытая карточка и её фото доступны владельцу и оператору. В Nginx `/api/` имеет приоритет над статическими `.jpg`.

SQLite schema 3 добавляет таблицу происхождения без удаления прежних записей. Новых env-переменных нет. Экспорт, фотографии, база, резервные копии и отчёты находятся вне Git либо в игнорируемых каталогах.
