# Импорт Telegram в локальную dev-версию

В Telegram Desktop экспортируйте группу `montenegrobye` (ID `1860715803`): JSON или HTML, фотографии, период за последние несколько недель. Дождитесь окончания экспорта. Прерванные файлы и другие группы импортёр отклоняет. Для HTML проверяется вся цепочка `messages.html` → `messages2.html` и далее: пустая, недописанная или отсутствующая следующая страница означает, что экспорт ещё не готов. HTML обрабатывается как данные, без запуска скриптов и загрузки внешних ресурсов.

JSON проверяется по ID группы. HTML не содержит надёжного ID: источник сопоставляется с известным полным названием группы из предоставленной пользователем папки. Такой импорт предназначен для локального наполнения; HTML-парсер использует dev-зависимость JSDOM, недоступную в production-образе.

Предпросмотр без изменения базы:

```powershell
npm.cmd run import:telegram -- --export "C:\путь\ChatExport_2026-11-06"
```

После проверки выборки добавьте `--apply` для записи. Необязательный `--wait` ожидает завершения экспорта до 12 часов. По умолчанию незавершённый файл сразу вызывает ошибку.

Команда использует только `data/blizu.sqlite` текущего проекта и требует демо-аккаунт; `DATA_DIR` намеренно игнорируется. При `NODE_ENV=production` запуск запрещён. Перед записью создаётся согласованная SQLite-копия через `VACUUM INTO` в `backups/before-telegram-*.sqlite`.

## Отбор и ограничения

- Выбираются 100 последних подходящих уникальных объявлений по времени исходного сообщения. Служебные записи, короткие ответы, объявления с пометкой «продано» в начале и повторы отбрасываются. Для длинных повторных публикаций одного автора изменение явно указанной цены не создаёт вторую карточку: сохраняется последняя версия. Это эвристика, а не поиск всех похожих товаров. Для записи нужны ровно 100 подходящих объявлений.
- Отбор и определение категории используют эвристики, без внешнего ИИ. Категория определяется по заголовку и первому предложению: упоминание бесплатной доставки или документов внутри описания товара не делает его услугой доставки или юридической услугой. Объявления без текстового описания не распознаются. Исходный текст сохраняется; ссылки с текстовой подписью разворачиваются в текст и URL. Строки из одних хештегов и приветствия не становятся заголовками.
- Альбомы объединяются по `media_group_id`, если он есть. Иначе используется осторожное правило: соседние фото одного автора, соседние ID, интервал не больше двух секунд, без второй отдельной подписи. Максимум 10 фото на карточку. Распознавание всех альбомов не гарантируется.
- Сохраняются дата, отображаемое имя автора и ссылка на оригинал. Числовой Telegram ID автора и служебные сведения экспорта в публичный API не передаются.
- Город указывается при однозначном совпадении. Иначе интерфейс предлагает уточнить его у автора.
- Единственная однозначная сумма в евро показывается как цена, включая `€40`, `40 €` и `40 euro`. Несколько сумм или валют остаются в тексте; карточка показывает «Цены в объявлении» / «Цена не указана». Бесплатные предложения различаются отдельно. При фильтрации по цене карточки с неопределённой ценой исключаются, при сортировке стоят в конце.

Предпросмотр сохраняется в `.context/telegram-import-report.json`. Перед первым применением проверьте выборку. Повторный запуск пропускает уже импортированные ссылки и тексты; существующие карточки и модерация не переписываются. Для изменённого объявления с прежней ссылкой автоматического обновления пока нет.

## Витрина и хранение

После импорта появляется переключатель «Из Telegram». Адрес подборки: `/?source=telegram&sort=newest#catalog`. Работают поиск, категории, сохранение, сравнение и модерация. Карточка показывает автора Telegram, происхождение и исходную дату. Кнопка ведёт к оригиналу: там можно связаться с автором и проверить актуальность. Заказ через blizu для внешнего объявления не предлагается. Системный аккаунт источника не позволяет войти в сервис и не получает вымышленных отзывов или отметок.

В локальном demo-режиме обычная выдача сначала показывает реальные записи, затем встроенные демо-примеры; сортировка «По рейтингу» сохраняет свой смысл. Примеры отмечены «Демо». Карточки поддерживают ручное листание альбома, сохранение и сравнение, показывают город, исходную дату и автора; фотографии товаров не обрезаются. Поиск учитывает имя автора Telegram. В списке городов добавлен Петровац.

Фотографии копируются в `data/uploads/listings/` с именами по SHA-256. Проверяются границы папки экспорта, сигнатура JPEG/PNG/WebP и размер до 10 МБ. API отдаёт только фото конкретной карточки и проверяет её видимость; скрытая карточка и её фото доступны владельцу и оператору. В Nginx `/api/` имеет приоритет над статическими `.jpg`.

SQLite schema 3 добавляет таблицу происхождения без удаления прежних записей. Новых env-переменных нет. Экспорт, фотографии, база, резервные копии и отчёты находятся вне Git либо в игнорируемых каталогах.

## Предоставленный экспорт

Первый JSON-экспорт 6 ноября 2026 года был прерван и содержал данные 2023 года; он не использовался. Повторный HTML-экспорт завершился на пяти страницах и содержал 4983 обычных сообщения. В локальную базу импортированы 100 уникальных объявлений за 3–5 ноября 2026 года с 277 фотографиями (52,2 МБ). Сохранены исходные описания, даты, авторы и ссылки. У 16 карточек вручную сокращены заголовки на основании текста и предоставленных фото; исправлены три случая цены с префиксом `€`. Прежние 8 демо-карточек сохранены. Резервная копия: `backups/before-telegram-1793969267194.sqlite`. Выборка, результаты проверки и редакторские изменения записаны в игнорируемый каталог `.context/`.
